# 做示例片时真实踩过的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 渲染时报 `gsap is not defined` | CDN 请求被断开 | 依赖全部下载到本地 `vendor/`（`scripts/fetch-vendor.sh`） |
| 第 0 帧该出现的东西没出现 | 在 0 秒用 `tl.set` 设置初始状态，seek 到 0 时没生效 | 初始状态直接写进 DOM／CSS |
| 太阳移动时一顿一顿 | 动画改的是 `left/top`，按整数像素跳 | 只动 `x/y/scale/opacity` |
| 车窗里什么都看不见，整窗一片棕色 | 自写的圆角矩形函数里带了 `beginPath()`，把“整屏减去窗口”的挖洞路径清掉了 | 画挖洞形状时第二个形状不要重新 `beginPath` |
| 天上飘着灰色柱子 | 水面倒影把桥墩也翻到了水面以上 | 画倒影前先裁剪到水面区域 |
| 近景树像重影 | 为了“动态模糊”叠了几层半透明副本 | 副本只留一层、透明度 0.15 以下，或者干脆不叠 |
| 3D 城市像橙色纸盒 | 雾把远处建筑染成了雾色 | 建筑不吃雾，用深色剪影，前面另加一块渐变雾墙 |
| 整片发白、标题被吃掉 | 太阳在画面正中＋泛光阈值太低 | 太阳移到画面边上或画外，泛光阈值提到 0.9 |
| 火车在桁架里看不见 | 下承式桁架挡住了车身 | 改成上承式（桁架在桥面下），车在桥面上跑 |
| 隧道里窗上有个大灰人影 | 车厢压暗后，窗上的“乘客倒影”太显眼 | 暗场景里倒影设为 0 |
| 成片 500 MB | 胶片颗粒几乎无法压缩，渲染器又是近无损 | x264 `-crf 21` 重压，约 130 MB／61 秒 |
| 转写出了“点赞订阅”之类不存在的话 | 语音识别在纯音乐段的幻觉 | 以试听为准，不要按转写改片子 |
