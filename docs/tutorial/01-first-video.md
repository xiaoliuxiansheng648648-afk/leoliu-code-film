# 第 1 课：它不是生成视频，是写代码——5 分钟做出第一条

> 视频版：《有人说Opus 5.5做不了视频？我实测5分钟出片》。下面的过程全部来自 2026-10-01 的一次真实会话（Claude Code，模型 Opus 5.5），时间、报错、用量都是原始记录。

## 1. 原理：它写网页，渲染器把网页拍成视频

Opus 5.5 是文本模型，不“生成”视频。它写的是一个网页：文字、图形、动画全是 HTML／CSS／JavaScript；再用开源工具 [HyperFrames](https://github.com/heygen-com/hyperframes)（Apache-2.0）把网页一帧一帧截下来，一秒 60 张，拼成 MP4。

所以网页能画的它都能做：文字排版、图表、粒子、甚至 Three.js 3D；做不了的是真人实拍那种画面。

## 2. 要装的东西

| 装什么 | 说明 |
|---|---|
| Claude Code | 模型选 Opus 5.5 |
| Node.js | 22 及以上（HyperFrames 的要求） |
| FFmpeg | 把截下来的帧压成视频 |
| HyperFrames | 不用单独装，用的时候 `npx` 自动下载；第一次渲染还会下载一个浏览器内核 |

## 3. 只说“帮我做一个视频”会怎样

实测：它没说做不了，也没要任何密钥，而是先反问三件事——

1. 这个视频主要讲什么？（产品宣传片／知识讲解／动态文字片头／数据可视化）
2. 画幅和用途？（竖屏 9:16 推荐／横屏 16:9／方形 1:1）
3. 大概多长？（15 秒推荐／30 秒／60 秒）

## 4. 第一句话：把这三件事说清楚

```text
用 HyperFrames 做一条 10 秒、1920×1080、60 帧的视频：黑底，一行金色的字“第一条，代码写的视频”逐字淡入，最后一道光从左扫到右。写完先跑 npx hyperframes lint 检查，有问题自己改，再渲染成 MP4，放在 out 文件夹。
```

“写完先检查、有问题自己改”这半句很重要：它会真的去跑检查并修。

## 5. 实测过程（23:22:11 发出 → 23:26:53 交付，4 分 42 秒）

| 时间 | 它在做什么 |
|---|---|
| 23:22:17–23:22:44 | 查 HyperFrames 版本，读 `--help` 和 `npx hyperframes docs` |
| 23:24:04 | 写 `index.html` |
| 23:24:09 | 检查：1 个错误（用了宋体却没写 `@font-face`）、2 个警告（嵌套结构要拆成子合成） |
| 23:25:25 | 拆成 `compositions/title.html`、`compositions/sweep.html`，补字体声明 |
| 23:25:28 | 检查：0 错误、0 警告 |
| 23:25:43 | 抽 5 帧看效果，放大看字和光 |
| 23:26:29 | 渲染 600／600 帧（约 15 秒） |
| 23:26:53 | 交付：1920×1080、60fps、10.0 秒、2.7 MB |

用量：30 次调用，输出 19,111 个 token。

## 6. 要发出去商用：先换字体

它默认用了 macOS 自带的宋体（Songti SC）。自己看没问题，做成视频公开发布、尤其商用，有字体授权风险。补一句：

```text
这条我要发到网上，字体换成能免费商用的开源字体（比如思源宋体），其他都不变，重新检查、渲染一版，第一版留着。
```

实测 3 分 42 秒出第二版：它把思源宋体（Noto Serif SC，SIL OFL 1.1）和许可证一起放进项目；检查报“资源路径越出项目根目录”后自己改成 `assets/...`；还自己发现新字体的逗号被金色渐变的裁切切平，加了内边距修好。

## 7. 能跑的 demo ≠ 能发的片

差在五件事：故事、风格、节奏、声音、检查。这个仓库的 `SKILL.md` 就是把这五件事写成固定步骤：先定故事和分镜，先出风格样张，再做 40 秒样片，然后全片、自检、配乐和渲染。两个完整示例在 `examples/`。
