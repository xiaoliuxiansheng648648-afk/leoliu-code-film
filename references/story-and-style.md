# 故事与风格

## 故事：先有人，再有画面

示例片最初是“北京西 → 石家庄 → 郑州……”一站一站念过去，本质是地名清单，和“11 种风格合集”一样没有情绪。改成“妈妈的消息串起回家路”以后才立住：

- **人物**：我（在车上）和妈妈（在家里），只靠手机消息出现，不用画脸。
- **期待**：一路在问“到哪了”，观众跟着等。
- **小反转**：隧道里信号断了，“快到了”没发出去。
- **落点**：最后一条“汤还热着”，前面所有画面都为这一句服务。
- **首尾呼应**：开场“回家”，结尾车票盖上“到站”。

检查清单：

- 第 0 帧一眼能看懂（中文大字＋清楚的主体），前 2 秒给结论或钩子。
- 每 5～8 秒要有新东西：新地点、新消息、新镜头。
- 片尾留一个开放问题（“你觉得哪一幕最不像代码画的？”），不要自问自答。
- 虚构的剧情在文案里标“剧情虚构”。

## 风格帧关：先画 3 张静帧

动画之前，先按最终质量渲 3 张静帧：开场、最强的一场、结尾，给用户确认。这一步最省时间：不满意就改风格或换路线，只动几张图。

示例片的路线比较（`docs/v2-v6-compare.jpg`）：

| 版本 | 做法 | 结果 |
|---|---|---|
| v2 | SVG 纯色块＋横向平移 | 像 PPT，被否 |
| v3 | Canvas 2D：逆光、雾、光束、泛光、颗粒 | 有氛围，适合车窗、室内 |
| v5 | Three.js：天空着色器、水面反射、雾、桥与列车 | 镜头能真正运动，适合大场面 |
| v6 | 2D 车窗 ＋ 3D 航拍 | 成片 |

## 光影配方（让简单形状看起来贵）

1. **逆光**：太阳放在画面里或画面边上，前景都变成剪影，只给边缘一道亮线（rim light）。剪影好画，又显得有电影感。
2. **分层大气**：远山、中景、近景颜色逐层向天空色靠近；层与层之间加一条雾带。
3. **光源发光**：太阳、灯、车窗单独画到一张“发光层”，模糊两次后以 `lighter` 叠回去（泛光）。
4. **光束**：从太阳发出十几条半透明三角形，`screen` 叠加。
5. **调色**：高光偏暖、暗部偏冷，`soft-light` 叠一层渐变。
6. **暗角和胶片颗粒**：颗粒每帧换位置，画面才“活”。
7. **车窗框**：室内压暗，窗外就亮；窗上的倒影和玻璃反光让它像真的车窗。

## 禁用清单（模板味的来源）

粒子爆炸、RGB 分离、镜头光晕贴图、满屏霓虹辉光、弹跳缓动的文字、每 4 秒换一种风格的合集、没有来由的 3D 旋转 logo。
